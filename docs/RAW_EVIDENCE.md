# Raw evidence and reproduction boundary

This repository contains selected source code, settings, summary statistics,
figures, and archived verification reports. It does not contain the complete
per-replication archives, server launch/exit receipts, or server logs.

The original reports and raw archives remain preserved separately by the
project owner. A passing archived verification report describes verification
against that original evidence; it does not mean every raw-data verifier can
run from this selected Git checkout alone. No public raw-archive download or
release has been created by this upload.

## Presentation and chronology

The CV project period describes the undergraduate project, not the execution
date of every subsequent repair, extension, or verification run. Original
execution metadata and run identifiers have not been rewritten or backdated.
The date-omitting results presentation is explicitly a derivative, not an
original execution record.

Original source/configuration hashes, summary JSON, CSV, and PNG bytes are
preserved. Workspace-link normalization affects copied Markdown only and is
listed in the publication manifest. Formal model fitting remains server-only.
